Capstone Project

CIS Capstone

Nonprofit Storytelling Tool

Complete

An AI-powered storytelling tool built for Viva Technology that helps nonprofit staff turn real-world experiences into polished written content. A local Llama 3.1 8B model conducts a guided interview to extract key story elements, which are anonymized and passed to the Claude API to generate audience-ready narratives for grant reports, donor appeals, social posts, and more. The hybrid architecture keeps sensitive staff and client data on-device while leveraging a more capable external model for the final writing output.

View on GitHub Download Final Report

Demo Walkthrough

Project Objectives

  • Build a functional two-model AI pipeline where a local LLM conducts structured interviews and the Claude API generates polished, audience-ready narratives
  • Deliver a deployable Flask web application with Docker Compose support, accessible to stakeholders via ngrok
  • Successfully generate coherent, goal- and audience-matched narratives from at least five real test stories with no PII leakage between the interview and API layers

Scope

In Scope:

  • Local LLM interview pipeline (Llama 3.1 8B via Ollama)
  • Claude API narrative generation layer
  • Goal and audience selection UI
  • Flask web application with Docker Compose
  • PII detection and readability scoring
  • Stakeholder demo access via ngrok

Out of Scope:

  • User authentication or saved accounts
  • Persistent narrative storage/database
  • Multi-language support
  • Mobile interface
  • Production cloud hosting
